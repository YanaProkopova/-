Тема: "Исследование применения нейронных сетей для подбора образа по фотографиям одежды"

Код: питон в vs code (Jupiter)

Интерфейс: HTML, CSS и JavaScript

По поводу датасета: я его еле откопала, чтобы были нормальные изображения, и в csv файле там есть такие категории image, sender_id, label, kids (название фото, id отправителя, тип вещи, подходит для детей или нет). Если есть возможность убрать sender_id и kids(они мне совсем не нужны), то было бы славно, если нет такой возможности, то в коде мы их просто пропускаем и не просматриваем. И еще один момент, в label иногда встречаются такие категории как Not sure, Other и Skip. Если их как-то тоже можно удалить, то будет замечательно, если нет, то просто также их пропускаем. 

Как должна работать программа: Пользователь загружает свои изображения, в нашем случае датасет, и программа должна определить что это за вещь(футболка, шорты и т.д.), какого она цвета(для гармоничного составления образов) и к какому стилю относится(спортивный, вечерний и т.д). И уже после этого пользователь выбирает в каком стиле он хочет образ, и нейронка это все создает и предлагает ему до 5-10 возможных образов. В образе должны быть до 4-5 вещей, обязательно чтобы была обувь, низ, верх и головной убор по желанию нейронки.
